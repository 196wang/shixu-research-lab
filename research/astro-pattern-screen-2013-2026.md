# BTC 与水逆、月相：2013–2026 固定口径复盘

研究日：2026-10-26；Bitstamp BTC/USD 价格数据截至 **2026-10-16**。完整数字见 [JSON](astro-pattern-screen-2013-2026.json)，可复算代码见 [脚本](../build_astro_pattern_screen.py)。这是看过历史和公开说法之后设计的**探索性研究**，没有盲测结果，也没有产生新交易规则。

## 公开说法与可检验的问题

- 一篇 [2020 年公开文章](https://medium.com/gains-associates/predicting-bitcoin-price-using-astrology-coincidence-or-fact-e76f4b18799a)举了 2018 年三次水逆和下跌的案例，同时认为牛市时水逆可能顺着上升趋势。它还把水逆结束的“恢复顺行”列作转向候选。这些是待检验的主张，不是已证实的规律。
- 一份[公开复算的 BTC 水逆研究](https://astrolog-app.com/en/studies/mercury-retrograde)用另一套 2011–2026 年 Bitstamp 日线与 JPL 星历，报告水逆期间的收益和波动都没有显著差异。我们的样本、日线边界和星历实现不同，因此独立复核方向是否稳定。
- [BTC 月相公开研究](https://github.com/rangiho/Bitcoin-Returns-and-Lunar-Phases)在 2015–2024 年样本没有找到稳定的收益、波动关系。另一篇[加密货币月相论文](https://www.acadlore.com/article/JAFAS/2025_11_3/jafas110304)虽然展示个别新月、满月窗口的正收益，但其自身的显著性检验也未通过 5% 阈值。

水逆是从地球看水星的**视运动**方向改变；水星本身没有在轨道上倒着运行，见 [NASA 说明](https://starchild.gsfc.nasa.gov/docs/StarChild/questions/question46.html)。天文事件的存在，不代表价格有因果反应。

## 数据、时间与比较方法

本机先前封存的 [Bitstamp 官方小时 OHLC](https://www.bitstamp.net/api/)共构成 2013-01-01 至 2026-10-16 的 5,037 个北京时间日期。主分析仅使用 4,979 个 24 小时完整且每小时有成交量的日线；另外 58 天剔除。原始响应和聚合日线的 SHA-256 校验由脚本执行，原始小时数据只存本机。与网站其他 Coinbase 数据不拼接。

用仓库固定的 [Astronomy Engine 2.1.19](https://github.com/cosinekitty/astronomy/blob/master/source/python/README.md)计算地心黄道经度：水星经度速度从正变负为“开始逆行”，从负变正为“恢复顺行”；用数值二分定位至一分钟内。新月与满月为日月地心黄经差 0° 与 180° 的精确时刻。事件按 **UTC+8** 归入日期；水逆起止的混合日不纳入“完整水逆日”与“完整顺行日”的比较。月相发生在一天内，因此单独列出事件当日和次日。

我们将历史拆成 2013–2020、2021–2023、2024–2026 三段。每个触发日与**同年同公历月**的非触发日期比；收益为北京时间当天开盘至收盘，波动为当日 `(最高−最低)/开盘`。另用“振幅达到此前连续 30 个合格日振幅中位数的 1.5 倍”作为大波动定义。这个阈值沿用先前固定筛选；如近 30 日有缺口，不能计算该项。分段本身是事后稳健性检查，不是提前锁定的未来样本。共检查多组事件，**不把单个看似突出的数字升级为预测能力**。

事件时刻核验：我们算得 2026-10-24 07:11 UTC 起逆、11-13 15:55 UTC 恢复顺行，与[公开星历表的 07:13 和 15:54 UTC](https://www.astro.com/astrowiki/en/Retrograde)相差两分钟内；微小差异来自一日中心差分的速度近似。2026-09-11、09-26、10-10、10-26 月相时刻与[美国海军天文台表](https://aa.usno.navy.mil/calculated/moon/phases?year=2026)相差不到一分钟。以上是**天文计算校验**，不是市场规则校验。2026-10-24 起逆晚于价格样本截止日期，未计入价格回测。

## 固定口径结果

| 候选 | 2013–2020 触发／同月对照 | 2021–2023 触发／同月对照 | 2024–2026 触发／同月对照 |
| --- | ---: | ---: | ---: |
| 完整水逆日：上涨比例 | 49.0% / 56.4%（524 日） | 51.9% / 48.2%（210 日） | 55.2% / 43.3%（172 日） |
| 水逆开始日：上涨比例 | 56.0% / 51.1%（25 日） | 30.0% / 49.7%（10 日） | 12.5% / 50.9%（8 日） |
| 恢复顺行日：上涨比例 | 56.0% / 55.6%（25 日） | 66.7% / 49.8%（9 日） | 66.7% / 51.2%（9 日） |
| 新月当日：上涨比例 | 53.6% / 54.1%（97 日） | 54.1% / 50.4%（37 日） | 45.7% / 54.0%（35 日） |
| 满月当日：上涨比例 | 51.5% / 54.2%（97 日） | 44.4% / 50.2%（36 日） | 61.8% / 54.1%（34 日） |

**完整水逆日“偏跌”的方向不稳定**：早段相对同月顺行日更弱，后两段反过来更强。近段“水逆开始日偏跌”有 7/8 的样本，但此前 25 日样本中有 14 日上涨，且起逆发生于日线中途。结束日的方向也只基于每段 9–25 日，不能据此提示买入或转势。

若看“大波动”，完整水逆日的触发/同月对照分别为 **26.2%/24.0%、23.2%/23.9%、14.0%/19.8%**，没有跨时段一致的波动放大。新月当天是 **29.2%/23.2%、14.7%/18.9%、33.3%/21.0%**，满月当天是 **27.3%/22.9%、21.9%/19.6%、21.9%/20.0%**；月相方向和大波动都不稳。新月及满月**次日**也另算在 JSON 中，未发现三个时段同向的上涨或大波动优势。

为检验“水逆起止是变盘点”，再用起止当日作为锚点，比较之前和之后各七天的收盘变化，要求方向相反且**两侧绝对变化都至少 2%**，事件当日排除。结果分别为 **11/49 = 22.4% 对同月份普通日期 25.7%**、**7/19 = 36.8% 对 29.5%**、**7/17 = 41.2% 对 22.9%**。近段虽高，但早段更低；“七天两侧变化”只有事后才能确认，不能回填成事前命中。对照是同月份日期的去重集合；事件锚点之间仍可能共享价格区间，所以这些比例不是独立伯努利试验。

## 对网站规则的处理

水逆、新月和满月适合作为**有确定发生时间的研究注释**，保留精确时刻、时区、行情源和事件种类。当前证据不足以把它们用于上/下跌权重、变盘日标记或与八字、江恩叠加后声称“共振更准”。若要继续检验，需要先固定一种主指标、风险阈值和样本截止日，在新增行情进入前登记；也要同时报告不触发日、同月份对照和交易成本。

本报告没有估算策略收益、费用、滑点或风险调整后表现，不构成投资建议。
